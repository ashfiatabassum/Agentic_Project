# Assignment brief (LMS, Module 13 project)

Copied from the LMS assignment page on 11 November 2026. This is the **grading/submission brief**. It does not list app features; those come from the separate **Project Requirements** lesson, summarised in [PRD.md](PRD.md).

## Task

In Module 13 the full project was built step by step (in PHP/Laravel). Build the same project independently with Claude Code and the course's agentic workflow, using a stack you have prior experience in. The video does not need to be copied line by line. Graders look for how the agentic workflow is used: **planning, giving good context, verifying the work, and fixing gaps**.

## What to do

1. **Read the requirements.** Re-read the Project Requirements lesson and understand what the app should do before starting.
2. **Set up the project.** Create a new GitHub repo and set it up as in Project Setup 1 & 2. Add a `CLAUDE.md` with the project's commands and rules.
3. **Design the data model.** Plan entities and relationships first. Keep the final model in the repo (short markdown file or diagram).
4. **Build the core features.** Use plan → implement → verify for each feature. Use **at least two** of: a subagent, a skill, a hook, an MCP server (Playwright for UI checks suggested), or OpenSpec.
5. **Try parallel work.** Run at least one task in a parallel session (Conductor or separate branches), then merge it cleanly.
6. **Check your work.** Run the app, compare it with the requirements, and note anything missing.

## What to submit

- GitHub repo link (public, or access granted to the reviewer's GitHub username).
- `README.md` in the repo with:
  - how to run the project;
  - which features are done and which aren't;
  - which agentic tools were used (subagent, skill, hook, MCP, etc.) and where.
- Screenshots or a short screen recording (2–5 minutes) showing the app working.
- Short reflection (200–300 words): What worked well with Claude Code? Where did it go wrong, and how did you fix it? What would you plan differently next time?

## LMS submission steps

1. Open the assignment and click **Add submission**.
2. Paste the GitHub repo link in the text box.
3. Upload the screenshots/recording and the reflection (PDF or DOCX).
4. Click **Save changes**, then **Submit assignment**.

A submission cannot be edited after it is submitted, so check everything first.
