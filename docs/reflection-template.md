# Reflection template — write after the project

**Submission requirement:** 200–300 words; export the completed reflection as PDF or DOCX. Do not submit this blank template.

Use four short paragraphs:

1. **What you built and your workflow (45–65 words):** Mention the actual working features, OpenSpec planning, and `CLAUDE.md` context.
2. **What worked well (45–65 words):** Give one specific example of a skill, reviewer subagent, Playwright MCP, hook, or parallel session that helped. Describe an observed result.
3. **What went wrong and the fix (60–80 words):** Name a real bug, incomplete AI output, incorrect assumption, or merge conflict. State how you verified and fixed it.
4. **What you would change next time (45–65 words):** Discuss scoping, tests, context, or integration sequencing based on actual experience.

Before exporting: count words, verify every claim against the repository and `docs/verification.md`, identify simulated billing accurately, and avoid saying every feature is finished if the README lists gaps.
